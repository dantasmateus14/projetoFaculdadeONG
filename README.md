# ONG Esperança

Site institucional desenvolvido para a ONG Esperança.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Git e GitHub

## Funcionalidades

- SPA com navegação por hash
- Layout responsivo
- Projetos gerados dinamicamente
- Validação de formulário
- LocalStorage
- Modal e Toast
- Recursos de acessibilidade

## Versionamento

O projeto utiliza Git e GitHub para controle de versão,
com commits seguindo o padrão Conventional Commits.

Versão atual: v1.0.0
